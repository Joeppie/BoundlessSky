# Reference screenshots

Layout and look-and-feel references captured from the running app (1440×900),
kept in-repo so future passes can compare the live screens against them.

- `hud-before.png` — the planet menu with the corner HUD showing system/date/credits (no ship yet, so no glyph).
- `hud-ship.png` — the corner HUD with a ship: the flagship glyph appears with shield (cyan, outer) and hull (olive, inner) rings.
- `shipinfo-desktop.png` — the Ship Info tab: left stat table (model, cost, shields/charge, hull, mass, movement, free capacities, energy/heat), right column of installed outfits grouped by category, bottom bar with Done.

These are visual references for the *look and layout*, not physics references:
ring percentages, fuel/heat and energy bars are decorative until the
resource model lands (Milestone 3).
